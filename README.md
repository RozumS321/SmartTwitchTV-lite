# SmartTwitchTV lite

Клиент Twitch для Android TV с новым интерфейсом. Это форк проекта
[fgl27/SmartTwitchTV](https://github.com/fgl27/SmartTwitchTV) с переработанным дизайном и упрощённым меню.
Сделан для себя и друзей.

> **English:** a personal fork of [fgl27/SmartTwitchTV](https://github.com/fgl27/SmartTwitchTV) (Android TV Twitch client)
> with a redesigned UI and a simpler menu. All credit for the app itself goes to Felipe de Leon (fgl27).
> Licensed under GPL-3.0, like the original.

Приложение не связано с Twitch и не одобрено им. Twitch — товарный знак Twitch Interactive, Inc.

## Что это за форк

Вся основа приложения — работа [Felipe de Leon (fgl27)](https://github.com/fgl27): плеер, чат, работа с API Twitch,
авторизация, уведомления, история и всё остальное. Этот форк меняет в основном внешний вид и навигацию.
Логика приложения осталась авторской.

Если приложение нравится, поддержите автора оригинала, ссылки на донаты есть в
[его репозитории](https://github.com/fgl27/SmartTwitchTV#donations).

Оригинальный README сохранён без изменений: [docs/README.original.md](docs/README.original.md).
Там подробно описано устройство приложения, сборка, переводы и разрешения авторизации.

## Чем отличается от оригинала

### Внешний вид

- Новая тема: тёмные цвета, фиолетовый акцент Twitch, шрифты Manrope и Space Grotesk.
- Иконки интерфейса заменены на SVG, вместо иконочного шрифта.
- Фокус пульта — толстое фиолетовое кольцо вокруг карточки.
- Сетки по 4 эфира и 6 категорий в ряд, карточки с подписями под превью.
- Уведомления стали тостами сверху по центру, окна и диалоги — тёмными панелями.
- Пустые экраны показываются карточкой с иконкой раздела, без загрузки картинки с сайта автора.

### Меню и экраны

- Одно меню вместо двух: страницы подписок перенесены в главное меню. Подменю «Подписки» убрано.
- Убраны экраны «В эфире», «Видео», «Клипы» и «Видео» из подписок.
  Видео и клипы игр и каналов остались на их страницах.
- **Главная** (с аккаунтом): подписки в эфире, под ними блок «Рекомендуемые».
  Если Twitch не отдаёт рекомендуемые для выбранного языка, показываются популярные эфиры на этом языке.
- Новый экран входа: карточка с кодом активации.
- **Настройки** разделены по разделам: слева список, справа строки раздела. Работает и с мышью.
- Переделаны поиск, страница канала (баннер, аватар, блок «О канале»), история, заблокированные,
  карточки каналов, переключатели на страницах игр и каналов.

### Плеер

- Новая панель: шапка с бейджем «В эфире / Запись / Клип», круглые кнопки, прогресс-бар.
- Выбор качества списком, как отдельная панель.
- Обновлены лента под плеером, превью перемотки и подписи окон мультистрима.

### Исправления

- В мультистриме не показывался значок звука у окон: код писал его в элемент, которого нет.

### Техническое

- APK загружает интерфейс с GitHub Pages этого форка: `https://rozums321.github.io/SmartTwitchTV-lite/`
  ([Constants.java](apk/app/src/main/java/com/fgl27/twitch/Constants.java)).
- Сборка APK — отладочная (`com.fgl27.twitch.debug`). Ставится рядом с оригинальным приложением и его не трогает.
- Аналитики нет: Firebase (Crashlytics, Analytics) убран из APK, Firebase и Google Analytics — из веб-части.
- Обновления идут из этого форка:
  - после каждой сборки сайта запущенное приложение предлагает перезагрузить интерфейс;
  - после каждой сборки APK приложение предлагает скачать и установить новую версию из
    [Releases](https://github.com/RozumS321/SmartTwitchTV-lite/releases).

## Установка на Android TV

1. Скачайте `SmartTwitchTV-lite.apk` из последнего релиза:
   [Releases](https://github.com/RozumS321/SmartTwitchTV-lite/releases/latest).
2. Установите его на телевизор через флешку и файловый менеджер, через Send Files to TV или `adb install`.
   На телевизоре нужно разрешить установку из неизвестных источников.
3. Дальше приложение обновляется само: интерфейс подгружается при каждом запуске, а о новой версии APK
   приложение сообщит и предложит её установить.

## Сборка

Всё собирается в GitHub Actions, на компьютере ничего ставить не нужно:

- [`.github/workflows/pages.yml`](.github/workflows/pages.yml) — при каждом пуше в `master` собирает веб-часть
  (`release/scripts/maker.js`: проверка jshint, сжатие JS, HTML и CSS) и публикует репозиторий на GitHub Pages.
  В настройках репозитория должно быть: **Settings → Pages → Source: GitHub Actions**.
- [`.github/workflows/apk.yml`](.github/workflows/apk.yml) — собирает APK вместе с изменённой автором
  библиотекой плеера [fgl27/media](https://github.com/fgl27/media) и выкладывает его релизом `apk-<номер>`.
  Запускается только вручную: Actions → APK → Run workflow.
  Все сборки подписываются одним ключом из секретов репозитория `SIGN_KEYSTORE_BASE64` и `SIGN_STORE_PASSWORD`,
  иначе обновление не встанет поверх старой версии. Без секретов APK только прикладывается к запуску, без релиза.
- Перед сборкой сайта [`.github/scripts/stamp-version.js`](.github/scripts/stamp-version.js) проставляет в
  `app/general/version.js` номер сборки сайта, номер последнего APK и заголовок последнего коммита.
  Это и есть описание изменений, которое приложение показывает в окне обновления.

Посмотреть интерфейс в браузере без сборки: запустите любой локальный веб-сервер в корне репозитория
и откройте `app/index.html`. Подробности — в [оригинальном README](docs/README.original.md#how-to-test-the-web-app).
